## 简介

W.ai 是一款轻量级的 AI 对话应用，基于 Android 平台开发。支持与 AI 进行自然语言对话，帮助用户完成各种任务。

## 功能特点

- 🤖 智能对话 - 与 AI 进行自然语言交流
- 💬 多轮对话 - 支持上下文理解
- 🎯 任务协助 - 写作、翻译、编程等
- 📱 轻量级 - APK 体积小巧，运行流畅
- 🔒 隐私安全 - 对话内容本地存储

## 下载安装

### 直接下载

[![下载 APK](https://img.shields.io/badge/下载-W.ai_1.0.apk-blue?style=for-the-badge&logo=android)](https://github.com/wangzi5151/tiny-ai/releases/download/v1.0/W.ai_1.0.apk)

### 系统要求

- Android 6.0 (API 23) 及以上版本
- 建议内存: 2GB+
- 存储空间: 50MB+

## 安装说明

1. 下载 APK 文件
2. 在手机设置中允许"安装未知来源应用"
3. 点击 APK 文件进行安装
4. 打开 W.ai 开始使用

## 使用示例

```
用户: 你好，请介绍一下你自己
W.ai: 你好！我是 W.ai，一个 AI 对话助手。我可以帮助你回答问题、撰写内容、翻译文本、编写代码等。有什么我可以帮助你的吗？

用户: 帮我写一首关于春天的诗
W.ai: 春风拂面暖如纱，
      桃花枝头笑哈哈。
      燕子归来寻旧巢，
      满园春色入新家。
```

## 技术架构

- **开发语言**: Java / Kotlin
- **UI 框架**: Material Design
- **网络请求**: OkHttp / Retrofit
- **数据存储**: Room Database
- **AI 引擎**: 云端 API
